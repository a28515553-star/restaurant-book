# وقت الصلاة (Salah Focus)

تطبيق أندرويد يحجب برامج التواصل الاجتماعي **قبل كل صلاة بعشر دقائق** ويفتحها **بعد الصلاة بعشر دقائق**، ويذكّرك بالصلاة بإشعارات.

## المزايا

- مواقيت الصلاة الخمس تُحسب على الجوال بدون إنترنت (أم القرى، رابطة العالم الإسلامي، المصرية، كراتشي) لمدينة تختارها أو لموقعك الحالي.
- حجب البرامج التي تختارها (فيسبوك، انستجرام، تيك توك، سناب، واتساب، تويتر، تيليجرام، يوتيوب... ويمكنك تغيير القائمة).
- مدة الحجب قبل وبعد الصلاة قابلة للتعديل (الافتراضي 10 دقائق).
- إشعارات: عند بدء الحجب، وعند دخول وقت الصلاة، وعند فتح البرامج.

## كيف يعمل الحجب

يستخدم التطبيق **خدمة إمكانية الوصول** فقط ليعرف أي تطبيق فُتح. لا يقرأ محتوى الشاشة. عند فتح برنامج محجوب داخل وقت الحجب تظهر شاشة تذكير بالصلاة مع عدّاد. فعّل الخدمة من: الإعدادات ← إمكانية الوصول ← وقت الصلاة (يوجد زر في الشاشة الرئيسية).

## البناء

- Kotlin + Jetpack Compose، minSdk 26.
- محلياً: `./gradlew assembleDebug` داخل مجلد `salah-focus`.
- GitHub Actions يبني الـ APK عند كل push على هذا المجلد، وعلى `main` ينشره في Releases باسم `salah-focus-latest`.
