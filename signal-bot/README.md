# بوت RSI(2) اليومية (تيليجرام)

يراقب كل عملات بينانس مقابل USDT اللي سيولتها اليومية فوق 5 مليون دولار، ويرسل على تيليجرام:
- 🟢 **شراء:** لما يغلق اليوم **فوق SMA200** ويكون **RSI(2) أقل من 5**، يعني تصحيح قوي داخل ترند صاعد.
- 🔴 **بيع:** البوت يتابع كل صفقة، ويرسل لك لما **RSI(2) يطلع فوق 70** أو بعد **10 أيام**، ومعه الربح أو الخسارة.

**ما يحتاج مفاتيح API، وما ينفذ أي صفقة.** يشتغل على GitHub Actions كل ساعة (`.github/workflows/stoch-bot.yml`).

## ليش هالاستراتيجية بس؟
اختبرنا كل الإشارات اللي كانت في البوت على بيانات بينانس الحقيقية (حوالي 60 عملة، بعد العمولة 0.2%)، وحذفنا كل اللي خسر أو كانت نتيجته غير ثابتة بين الاختبارات:

| الإشارة | النتيجة | الحالة |
|---|---|---|
| **RSI(2) اليومية** | **+2.04%** لكل صفقة (237 صفقة، 65% رابحة)، وربحت في كل الأقسام | ✅ باقية |
| Stoch RSI + ماكدي + فلتر EMA | بين -0.40% و+0.28%، وغير ثابتة بين الاختبارات | ❌ محذوفة |
| اختراق الترند النازل | -0.31% | ❌ محذوفة |
| ارتداد من دعم قوي | -0.94% | ❌ محذوفة |
| اختراق مقاومة قوية | -0.07%، وقلبت من ربح لخسارة على 4 ساعات | ❌ محذوفة |
| مناطق العرض والطلب مع سحب السيولة (5m و15m) | -0.25%، مثل الدخول العشوائي | ❌ محذوفة |

النتائج من الماضي، وما فيه ضمان للمستقبل.

## الملفات
- `stoch_bot.py`: البوت.
- `rsi2.py`: قواعد الشراء والبيع.
- `common.py`: جلب بيانات بينانس العامة والمؤشرات.
- `backtest_rsi2.py`: الاختبار التاريخي، ويشتغل يدوياً من Actions (**Backtest RSI(2) daily**).

## الإعدادات
- الأسرار: `TELEGRAM_BOT_TOKEN` و`TELEGRAM_CHAT_ID`.
- متغيرات اختيارية: `R2_MIN_VOLUME` (الافتراضي 5000000)، و`SYMBOLS` (`ALL` أو قائمة مثل `BTCUSDT,ETHUSDT`).
- للتشغيل على جهازك: `pip install -r requirements.txt`، وبعدها انسخ `.env.example` إلى `.env`، وشغّل `python stoch_bot.py`. وإذا تبي رسالة تجربة: `TEST=1 python stoch_bot.py`.
