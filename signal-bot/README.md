# بوت إشارات بينانس سبوت (تيليجرام)

يراقب عملات بينانس ويرسل لك على تيليجرام **إشارة شراء** عند بداية الارتداد داخل ترند صاعد، مع الهدف والوقف، ثم يبلغك عند لمس الهدف 🟢 أو الوقف 🔴.
**لا يحتاج مفاتيح API ولا ينفذ أي صفقة** — القرار لك.

## الاستراتيجية
شراء فقط إذا تحققت كل الشروط على إغلاق شمعة 15د:
| الشرط | المؤشر |
|---|---|
| الاتجاه صاعد على 15د و1س | السعر > EMA200، EMA50 > EMA200 |
| بداية الارتداد | Stoch RSI: تقاطع K فوق D بعد نزوله تحت 20 |
| زخم صحي | RSI بين 45 و65 وصاعد |
| تأكيد الزخم | هيستوجرام MACD يتزايد |
| قوة الترند | ADX > 20 و +DI > -DI |
| سيولة | الفوليوم > متوسط 20 |
| ضد الدخول المتأخر | السعر لا يبعد عن EMA20 أكثر من 1×ATR |

الهدف الافتراضي 1.2% والوقف 0.8% (عمولة بينانس ~0.2% ذهاباً وإياباً).

## التشغيل (مرة واحدة)
1. ثبّت Python 3.10+ ثم:
   ```
   pip install -r requirements.txt
   ```
2. **أنشئ بوت تيليجرام:** افتح `@BotFather` ← `/newbot` ← انسخ التوكن.
3. **رقم المحادثة:** أرسل أي رسالة لبوتك، ثم افتح
   `https://api.telegram.org/bot<التوكن>/getUpdates` وانسخ رقم `chat.id`.
4. انسخ `.env.example` إلى `.env` وضع التوكن والرقم والعملات.
5. **اختبر أولاً:**
   ```
   python bot.py --backtest
   ```
   إذا كانت نسبة النجاح أقل من ~55% أو الصافي سالب لعملة ما، احذفها أو غيّر الهدف/الوقف.
6. **شغّل المراقبة:**
   ```
   python bot.py
   ```
   يفحص كل دقيقة. ليعمل 24 ساعة شغّله على سيرفر VPS رخيص أو جهاز يبقى مفتوحاً.

بدون تيليجرام يطبع الإشارات في الشاشة فقط.

## الإعدادات (`.env`)
| المتغير | الافتراضي | المعنى |
|---|---|---|
| `SYMBOLS` | BTC,ETH,SOL,BNB,XRP | العملات (مقابل USDT) |
| `INTERVAL` | 15m | فريم الدخول |
| `TREND_INTERVAL` | 1h | فريم الاتجاه |
| `TP_PCT` / `SL_PCT` | 1.2 / 0.8 | الهدف والوقف % |
| `MAX_ATR` | 1.0 | أقصى بُعد عن EMA20 (أقل = دخول أبكر وصفقات أقل) |

## TradingView
`strategy.pine` نفس الاستراتيجية لرؤية الإشارات على الشارت وعمل Strategy Tester.

> أداة تعليمية وليست نصيحة مالية. لا توجد استراتيجية تضمن الربح؛ اختبر وابدأ بمبلغ صغير وضع وقف الخسارة دائماً.

## بوت Stoch RSI لجميع العملات (`stoch_bot.py`)
يشتغل على GitHub Actions كل 5 دقائق، ويفحص **كل أزواج USDT في بينانس** على فريمات **15 دقيقة وساعة و4 ساعات** اللي سيولتها اليومية فوق مليون دولار. يرسل فرصة شراء لما **Stoch RSI ينزل تحت 20 ويبدأ يخترقه للأعلى**، و**الماكدي إيجابي**، و**RSI أقل من 70**. ما يكرر نفس الإشارة.
- الأسرار: `TELEGRAM_BOT_TOKEN` و`TELEGRAM_CHAT_ID`
- المتغيرات (اختيارية): `INTERVAL` (الافتراضي `15m,1h,4h`)، و`LEVEL` (20)، و`RSI_MAX` (70)، و`MIN_VOLUME` (1000000)، و`SYMBOLS` (ALL أو قائمة)

### تنبيه اختراق الترند النازل (`trend.py`)
على فريم الساعة و4 ساعات (`BREAKOUT_TF`)، البوت يرسم خط الترند النازل بين أعلى قمة وآخر قمة أقل منها، ويرسل تنبيه لما شمعة تغلق فوقه بفوليوم أعلى من المتوسط بـ1.5 مرة. يرسل معه الدعم والوقف تحته، وأقرب مقاومة كهدف أول، وقمة الترند كهدف أبعد. يتجاهل الإشارة إذا كان الوقف أبعد من 15% أو أبعد من قمة الترند.

### تنبيه الدعم والمقاومة القوية (`zones.py`)
على الفريم اليومي افتراضياً (`ZONE_TF`، وتقدر تكتب `1d,4h`). البوت يجمع القمم والقيعان القريبة من بعض في مناطق، ويعتبر المنطقة قوية إذا لمسها السعر 4 مرات منفصلة أو أكثر (بين كل لمسة والثانية 10 شموع)، وكانت تبادلت الأدوار (مقاومة صارت دعم أو العكس)، أو لمسها 6 مرات وأكثر. ويرسل تنبيه لما السعر يرجع لها بعد ما ابتعد عنها، ويقول إذا ارتد منها أو كسرها.
