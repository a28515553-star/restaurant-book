# لجنة تدقيق الصور

تطبيق ويب (يعمل على الجوال ويمكن تثبيته كتطبيق): ترفع صورة (طبق، منيو، شاشة المطعم، إعلان سوشال، واجهة المطعم)، وتدققها **لجنة من مدققين بالذكاء الاصطناعي (Claude)**. كل مدقق يشوف الصورة بعين شخصية معيّنة وله مهمة محددة:

**العملاء**
| المدقق | مهمته |
|---|---|
| 🍔 العميل الجائع | هل الصورة تفتح النفس وتخليه يطلب الآن؟ |
| 💰 العميل الحريص على فلوسه | هل المنتج والحجم والسعر واضحين؟ هل يحس بخداع لما يستلم؟ |
| 📱 عميل السوشال ميديا | هل تنفع للنشر وتخليه يزور عشان يصوّر؟ |
| 👨‍👩‍👧 رب الأسرة | الكمية، مناسبة للأطفال، النظافة، المكونات والحساسية |

**فريق المطعم**
| المدقق | مهمته |
|---|---|
| 🏪 صاحب المطعم | هل تبيع وتمثل الهوية؟ هل تعِد بشي المطبخ ما يقدر يقدّمه؟ |
| 👨‍🍳 الشيف | الطزاجة، درجة الطبخ، الترتيب، هل تشبه الطبق الحقيقي |
| 🎨 المصمم والمسوّق | التكوين، الإضاءة، وضوح النص العربي وأخطاؤه، مناسبة المقاس |
| 🧼 مراقب الجودة والأنظمة | النظافة، الادعاءات المبالغ فيها، السعرات والحساسية في المنيو |

- كل مدقق يعطي: **تقييم من 10**، جواب سؤاله (نعم / ربما / لا)، رأيه بجملة، وإيش عجبه، والمشاكل، والتعديل المقترح.
- بعدها **رئيس اللجنة** يجمع الآراء: الحكم النهائي (اعتمدها / عدّل عليها / أعد التصوير)، وين اتفق العملاء والمطعم ووين اختلفوا، وأهم التعديلات بالترتيب.
- تقدر تشغّل أو توقف أي مدقق، وتضيف **مدقق بمهمة خاصة** (مثلاً: عميل نباتي، عميل رياضي يحسب السعرات).
- زر «نسخ التقرير» ينسخ التقرير كنص ترسله للمصمم أو المصور.

**المفتاح:** يحتاج مفتاح Anthropic API من console.anthropic.com. المفتاح يتحفظ في المتصفح على جوالك فقط ويُرسل مباشرة إلى Anthropic. كل مدقق طلب مستقل (8 مدققين + الخلاصة = 9 طلبات للصورة الواحدة)، فقلل المدققين إذا تبي تقلل التكلفة.

**الرابط:** بعد الدمج في `main` ينشر على GitHub Pages تحت `/reviewers/`.

**للمطورين:** المدققين وتعليماتهم في `reviewers.js`، والواجهة في `app.js`. يستخدم `@anthropic-ai/sdk` (مضمّن في `anthropic-sdk.js`) مع الموديل `claude-opus-5-5` والردود المنظمة (Structured Outputs). الاختبار: `node image-reviewers/test.js`
