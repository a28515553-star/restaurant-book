# دفتر المطعم

تطبيق أندرويد بالعربي لتسجيل مصروفات المطعم اليومية والرواتب والدخل، ويحسب الربح أو الخسارة لكل شهر.
يعمل بدون إنترنت، وكل البيانات محفوظة على الجوال نفسه.

## ماذا يفعل

- **المصروفات:** سجّل كل مصروف بنوعه (غاز، خضار، لحوم، كهرباء...) والمبلغ والتاريخ. تظهر المصروفات مقسّمة حسب اليوم مع مجموع كل يوم ومجموع الشهر. يمكن إضافة أنواع جديدة أو حذف الأنواع غير المستخدمة.
- **الرواتب:** سجّل راتب كل موظف. الأسماء السابقة تظهر كاقتراحات لتسريع الإدخال.
- **الدخل:** سجّل دخل كل يوم.
- **التقرير:** لكل شهر يعرض إجمالي الدخل، إجمالي المصروفات، إجمالي الرواتب، ثم النتيجة: **ربح** بالأخضر أو **خسارة** بالأحمر. ويعرض أيضاً مجموع كل نوع مصروف ونسبته، ومجموع رواتب كل موظف.
- اضغط على أي سجل لتعديله، أو على أيقونة سلة المهملات لحذفه. أسهم الشهر في الأعلى تنقلك بين الأشهر.

## التثبيت على الجوال

كل تحديث على فرع `main` يبني ملف APK تلقائياً عبر GitHub Actions وينشره في صفحة Releases باسم `latest`.
افتح الرابط من الجوال، نزّل `restaurant-book.apk`، واسمح بالتثبيت من مصادر غير معروفة عند السؤال.

## للمطورين

- Kotlin + Jetpack Compose (Material 3) + Room
- minSdk 26، compileSdk 35
- البناء: `./gradlew assembleDebug`

```
app/src/main/java/com/ibrahim/restaurantbook/
  data/   الجداول (Entities) والاستعلامات (DAOs) وقاعدة البيانات
  ui/     الشاشات: المصروفات، الرواتب، الدخل، التقرير
```
