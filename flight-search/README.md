# مقارن أسعار الطيران

تطبيق ويب (يعمل على الجوال ويمكن تثبيته كتطبيق) — تكتب الرحلة مرة وحدة، ويفتح لك نفس البحث جاهزاً في كل مواقع الحجز:
Google Flights، Skyscanner، Kayak، Momondo، Cheapflights، Wego، المسافر، Booking.com، Expedia، Trip.com، Aviasales.

- بحث المطارات بالعربي أو الإنجليزي أو برمز المطار (أي رمز IATA يُقبل).
- ذهاب فقط أو ذهاب وعودة، عدد البالغين/الأطفال/الرضّع، الدرجة، العملة.
- اكتب السعر اللي ظهر لك في كل موقع ← يحدد لك **الأرخص** تلقائياً ويحفظ الأسعار.
- زر «أرخص يوم في الشهر»، وحفظ آخر عمليات البحث.

**الرابط:** بعد الدمج في `main` ينشر على GitHub Pages تحت `/flights/` (مثل `https://<user>.github.io/restaurant-book/flights/`).
من الجوال: افتح الرابط ← قائمة المتصفح ← «إضافة إلى الشاشة الرئيسية».

**الاختبار:** `node flight-search/test.js`

> لماذا لا يجلب الأسعار تلقائياً؟ مواقع الحجز تمنع سحب الأسعار من تطبيقات خارجية، والـ APIs الرسمية مدفوعة أو تحتاج اتفاقية شراكة. لذلك التطبيق يفتح البحث الجاهز في كل موقع بضغطة، وأنت تقارن.
